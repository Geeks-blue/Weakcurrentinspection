# 弱电巡检 微信小程序

## 快速配置

### 1. 填写后端地址
编辑 `miniprogram/app.js`，修改第 5 行：
```js
baseUrl: 'http://your-server-ip:8000'  // ← 改为实际后端 IP
```
> 注意：微信小程序不支持 localhost，需要填写局域网 IP 或公网域名。
> 正式发布时需要在微信公众平台配置合法域名（request 合法域名）。

### 2. 填写 AppID
编辑 `miniprogram/project.config.json`，将 `appid` 替换为实际小程序 AppID。

### 3. 开发工具导入
在微信开发者工具中选择「导入项目」，目录指向 `miniprogram/`，填写 AppID 即可。

## 功能说明

### 账号自动切换
登录后根据角色自动跳转：
- **学生** → 学生端（任务列表 → 扫码巡检 → 记录查看）
- **管理员/教师** → 管理端（待审核 → 记录总览 → 派发任务）

### 学生端
| 页面 | 功能 |
|------|------|
| 我的任务 | 查看待巡检任务，点击进入巡检 |
| 巡检签到 | 微信扫码签到 / 手动输入房间码，填写巡检项目，上传照片 |
| 巡检记录 | 查看历史提交记录 |

### 管理端
| 页面 | 功能 |
|------|------|
| 待审核 | 查看待审核巡检，一键通过/驳回/要求整改 |
| 记录总览 | 按状态/房间/学生筛选所有巡检记录 |
| 派发任务 | 选择房间+学生，自动楼栋均分派发（保留性别限制逻辑） |

## 目录结构

```
miniprogram/
├── app.js              # 全局状态（token、user、baseUrl）
├── app.json            # 页面路由配置
├── app.wxss            # 全局样式
├── project.config.json # 项目配置（AppID）
├── utils/
│   ├── api.js          # 所有后端 API 调用
│   └── format.js       # 状态标签/日期格式化
└── pages/
    ├── login/          # 登录页（公共入口）
    ├── student/
    │   ├── tasks/      # 学生任务列表
    │   ├── inspect/    # 巡检表单（扫码+拍照+提交）
    │   └── history/    # 我的巡检记录
    └── admin/
        ├── review/     # 待审核（含审核操作）
        ├── records/    # 巡检记录总览
        └── dispatch/   # 任务派发
```
